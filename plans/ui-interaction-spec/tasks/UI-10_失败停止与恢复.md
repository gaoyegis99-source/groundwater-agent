# UI-10：失败停止与恢复

## 目标
完善停止请求、失败详情、恢复批次和新确认。

## 前置依赖
UI-08, UI-09

## 源码范围
- `use-message-actions.ts`
- `WorkspacePanel.tsx`
- `RecoveryCard`

## Codex 执行步骤

## 测试命令
```bash
Stop/recovery tests；E2E race/recovery。
```
执行前核实本地 package scripts、pytest 配置、执行手册和环境，不得猜测不存在的命令。

## 验收标准
取消以服务端为准；恢复不复用旧确认；成果不丢失。
