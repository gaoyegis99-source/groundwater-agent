# Data Quality 与科研适用性设计草案

## 三层质量
A. 文件质量：解析、格式、列结构、类型、编码、checksum、损坏/空文件。
B. 数据规则质量：空值、重复、范围、时间格式、单位一致性、坐标有效性、异常值规则。
C. 研究适用性：按方法要求判断，不是 Dataset 全局 PASS。

示例：
- 趋势分析：时间字段、观测变量、有效样本量、时间覆盖、缺测/季节性信息。
- 流场分析：井位、坐标参考、观测水位语义、垂向基准。
- 空间插值：点位分布、样本数量、目标变量、空间参考。
- 数值模拟：网格、参数、初始/边界条件。

## 质量回执
复用 QualityRun，核实能否记录 dataset/version/semantic revision、suite/rule version、真实执行身份（若由 Executor 执行）、输入 checksum、结果/指标/问题明细、输出证据、时间和错误信息。

如果结果只是用户或外部提交的声明，必须标明来源，不能伪装成平台实际执行。

## 局部阻塞
同一数据集可以支持时序分析但不支持流场分析。Data 提供自己拥有的文件和数据规则事实；不修改 Kernel 任务/分支状态机。

## 验收
文件可读不代表科研可用；关键单位/基准缺失保持 UNKNOWN/BLOCKED；结果绑定精确版本和规则版本；相同输入和规则版本可复现。
