# 系统工程包验收矩阵

- [ ] 本地产品版本、工具链、HEAD 和工作区状态有证据。
- [ ] Kernel/Data/Knowledge/Executor 的状态所有权清楚，无平行真相。
- [ ] Agent 路由、确认、拒绝、恢复和断线重连符合既有状态机。
- [ ] Data 目录、分页、版本、查询、预览接口契约一致。
- [ ] Knowledge 检索结果必须完整读取后才可作为引用证据。
- [ ] Workflow DAG 编译、端口绑定、循环检测和输出验证正确。
- [ ] Executor 节点状态、重试、恢复和成果发布可追溯。
- [ ] ConfirmationEditor 能检索/选择数据集，错误可见且可重试。
- [ ] Workflow Draft 展示准确且不产生执行授权。
- [ ] 地图/图表通用组件正确处理大数据、排序、轴类型、CRS 和 NoData。
- [ ] 结果查看、下载、比较和复用不混淆数据版本。
- [ ] 相关单元、子系统、E2E、typecheck/build 和性能检查真实执行。
- [ ] 所有 NOT_RUN/UNKNOWN 项明确保留。
