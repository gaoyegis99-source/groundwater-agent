# 系统级工程完善总计划

## 目标
让现有 Groundwater V6 成为稳定、可靠、易用、可维护的地下水科研工作流平台底座。此阶段不扩展专业模型能力。

## 六个工作包
- E1 架构与工程质量：模块职责、合同一致性、依赖、文档、缺陷基线。
- E2 Agent 运行机制：意图路由、上下文、工具调用、确认、恢复、异常。
- E3 Data/Knowledge 基础设施：目录、版本、语义、查询、预览、证据和血缘。
- E4 Workflow/Executor：DAG、编译、调度、节点状态、重试、恢复、发布。
- E5 Web 工作台：确认、草稿、数据工作台、地图/图表通用组件、结果体验。
- E6 测试与性能：分层测试、E2E、性能、并发、恢复、可复现反馈。

## 任务清单
### E1
- SYS-01 本地基线与产品装配核验
- SYS-02 架构边界与接口合同审计
- SYS-03 缺陷台账与历史审计校准

### E2
- SYS-04 Agent 状态机与交互恢复回归
- SYS-05 上下文、路由和工具调用边界验证

### E3
- SYS-06 Data 目录分页、版本和查询链路
- SYS-07 Knowledge 检索、证据读取和引用追踪

### E4
- SYS-08 Workflow DAG 合同和编译能力验证
- SYS-09 Executor 节点状态、恢复和成果发布

### E5
- SYS-10 ConfirmationEditor 数据集分页与错误状态
- SYS-11 Workflow Draft DAG 展示与缺项交互
- SYS-12 地图/图表查看器通用缺陷修复
- SYS-13 结果查看、比较和复用体验

### E6
- SYS-14 分层回归、性能与工程验收

## 依赖原则
SYS-01 是所有任务的前置核验。SYS-02/03 完成后再进入跨模块修改。SYS-04 至 SYS-09 按职责串行推进。SYS-10 至 SYS-13 依赖后端合同稳定。SYS-14 最后执行阶段验收。

## 非目标
- 不做地下水趋势、Kriging、DRASTIC、MODFLOW、Pastas 算法完善。
- 不将系统改造成通用 GIS Agent。
- 不重写 Kernel/Data/Knowledge/Executor。
- 不做部署、安全、鉴权、多租户专项重构，除非发现直接阻断当前功能的已证实缺陷并经用户批准。
