# ADR · Data v3 的版本化语义与发现条件

状态：实施决策，2026-11-14。附件要求公共合同变更先提交 ADR。本决策涉及 Data v3 和 data-tools-v4 的可选字段。

Data 已有不可变对象、版本、CAS 语义修订和质量运行。将量类型、字段角色、字段出处及适用范围加到现有语义修订，将带 CRS 的二维包围盒加入同一修订。范围为调用者声明，栅格头与全表画像继续放在物理 descriptor。旧记录保留未知。Data 通用层只校验结构与可比较性，地下水词表归领域包。

发现接受可选的精确量类型、日期覆盖和同 CRS 空间交集。存在字段和单位条件时，每个字段条件须由满足单位及量类型条件的列支持。字段名只提供字面搜索。候选继续返回精确版本和语义修订，并补足垂向基准、空间范围和对应质量摘要。时间筛选接受 ISO 日历日期，目录已有的年、月精度按覆盖区间解释。空间筛选要求同一登记 CRS，重投影由明确的下游变换处理。用户可在版本详情核对来源和限制。

质量读取优先复用现有 QualityRun。以 DatasetVersion、SemanticRevision 和当前启用绑定修订核对快照，旧质量结论不沿用。科研适用性按分析分支判定，依赖字段角色、时间、空间、单位和基准。历史质量运行、语义修订、数据版本与血缘继续经既有入口读取。

备选方案是把所有语义压入描述字段，或者建立独立事实索引。前者无法做稳定的量与范围判定，后者需维护双份状态和权限。采用现有语义 JSONB 和发现投影，无需迁移或新数据库。结构化筛选属于候选缩小，不代表科学适用性或证明坐标真实。

验收覆盖旧数据读取、同名异义、跨列单位、日期边界、未知空间范围、异 CRS、同语义质量、版本变更和历史读取。生成并核验 HTTP、SDK 与工具合同。旧请求仍可按已有参数调用。
